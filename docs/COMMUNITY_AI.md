# 多来源情绪与 DeepSeek 接入

本版本将公开社区验证、分类、扫描分开记录。个股页默认使用新浪股吧和 DeepSeek；也可以选择淘股吧。原东方财富规则口径独立保留，不合并分母或回算旧快照。

## 本机配置

项目根目录 `.env.local`（已被 Git 忽略）或服务端环境变量：

```dotenv
SENTIMENT_AI_BASE_URL=https://api.deepseek.com
SENTIMENT_AI_MODEL=deepseek-flash
SENTIMENT_AI_API_KEY=填写自己的密钥
SENTIMENT_AI_DAILY_CALL_LIMIT=50
```

环境变量优先，配置文件每次分类读取，修改密钥无需重启。该适配器使用官方 OpenAI 兼容 Chat Completions JSON 输出接口，支持 `deepseek-flash`、`deepseek-v4-pro`。不使用 Anthropic 地址。密钥只在后端发送给 DeepSeek，不放进 `VITE_` 变量、Git、响应或分类记录。官方文档：[调用方式](https://api-docs.deepseek.com/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。

每日限额按北京时间自然日计算，包含失败调用的预约记录。默认50次用于先验证质量与费用；**不代表50次就能分析完整市场**。扫描达到限额后继续采集，合格样本进入独立的 `awaiting_ai` 队列，不会静默切换成规则。个股主入口也可明确选择“免费关键词规则（非AI）”，无需模型额度，统计口径与AI分别标注。相同观察批次、模型、提示词的成功结果直接复用。401/403/402/429暂停模型调用10分钟，错误响应原文不返回客户端，公开采集继续；源站本身拒绝访问仍暂停。

## 来源验证口径

| 来源 | 固定入口 | 当前适配 |
| --- | --- | --- |
| 新浪股吧 | `guba.sina.cn/list_{sh/sz/bj}{code}.html` | 核验证券代码与交易所，提取可见标题/正文、作者和显示时间；支持GBK页面 |
| 同花顺圈子 | `t.10jqka.com.cn/guba/{code}/` | 核验证券身份；实测静态个股页未取得可核验帖子，仅报告入口，不使用投顾首页代替散户讨论 |
| 淘股吧 | `www.tgb.cn/quotes/{sh/sz/bj}{code}` | 核验证券身份；北交所代码字段包含bj前缀；只采主帖T，排除回复、机构调研和其他条目 |

每来源每股票10分钟内复用；401/403/423/429/451、验证码标题或跳转不继续请求，该来源暂停30分钟。来源相互独立，不绕过验证。单页15秒、2MB上限，不跟随跳转、不执行页面脚本。

七天成功率区分“HTTP入口可达”和“取得可读样本”；统计实际请求次数、成功样本覆盖的独立股票数与完整目录分母。重复采集不等于独立帖子，诊断文件重解析不计入真实请求成功率。公开帖子、来源哈希、原文显示时间和采集时刻追加保存。

新浪列表的时分/短日期、淘股吧的`actionDate`目前都不视作已核验的完整发布时间。新来源统计是**页面观察快照**，不是当日/近3日发帖总量，不写入原发布时间情绪曲线或历史收益回测。

## 分类与样本门槛

先按内容去重、过滤明确引流广告，并排除只有其他上市证券标签的讨论（例如港股00981不直接算A股688981）；每账号每批最多3条，记录高频账号迹象，不宣称确认机器人身份。最多30条进入单次请求。模型围绕具体目标代码和名称判断看多/看空/中性、相关性、营销及恐慌/追涨/贪婪/抄底/踏空/套牢标签。账号ID不发送给模型。

JSON结果必须完整、一一对应原样本ID、标签与字段均通过严格校验，完成原因须为stop；空白、截断、额外/缺失ID整体拒绝。置信度低于0.6、广告、无关讨论排除。不把置信度当成上涨概率。

舆论分=`100×看多/(看多+看空)`，无方向样本留空；分布比例分母含有效中性。至少20条有效样本、10位作者、10条方向样本、24小时内观察才入榜。方向一致度仅描述方向样本的偏向。低样本仍可查分布，但明确标记不足。规则分类单独标注“非AI”，其中未识别不等于真实中性。

## 扫描与报告

全市场任务保存完整股票池以及**来源、模型、提示词版本、统计时间口径**，一个批次不切换方法。新扫描可选新浪、淘股吧或原东方财富；同花顺尚不用于全市场情绪扫描。“全市场”表示遍历A股股票目录，**不等于全网所有平台和所有帖子**。按已处理股票数均衡推进沪深北三个市场，避免代码排序使部分排名长期只有北交所。自动计划保存所选口径，每日16:10运行，需后端持续在线。

扫描在内容去重、广告与异证券过滤、作者限额后预筛；少于20条候选或10位作者时，直接记录“未请求AI、样本不足”，保留原始与候选数，**不生成多空计数或分数**，不浪费扫描模型额度。个股手动AI分析仍允许小样本，但明确标记不足。

AI额度或配置受限时，已采集样本保存为待分类，其他股票继续采集。全部采集处理结束后，批次为 `waiting_ai`（采样结束、AI待补充），释放采集队列供下一日任务使用；模型额度恢复且无正在采集的批次时自动补充最近待处理批次。24小时以内复用保存的原样本，超过24小时重新采样再分类，不把旧快照当作当天结果。模型暂时故障仅重试分类阶段，访问拒绝不绕过。重启保留阶段、观察ID和重试时刻。

页面/API分别披露“取得帖子、完成分类、满足入榜、AI待处理”及沪深北分母；样本不足、来源失败与模型失败单列。预筛未分类和待分类不当作中性，不进入排名。CSV包含采样状态、分类状态、原始及候选帖子数。受50次额度、低样本或来源不可达影响时，AI排名仍是部分覆盖；需要完整AI覆盖须另行评估成本或接入本地模型，不能只靠继续采集解决。

短暂网络/服务端故障最多自动重试2次，分别等待11、22分钟，重启保留重试计划；其他股票继续处理。单股404/410只记录来源无可用页面，不能据此连续暂停全站。访问拒绝立即暂停，连续解析失败暂停检查，失败不进入排行榜。采集与模型调用使用独立的系统锁；进程异常退出后系统释放锁，避免遗留标志使页面永久不可用。

采样结束（含AI待补充）和批次处理结束时，会自动追加保存复盘报告；待分类报告明确保留部分覆盖状态。`GET /api/live/market/report?scan_id=...`从保存的批次结果生成报告，包括目录覆盖、达标股票等权舆论分、方向极值，以及相对同口径已完成批次的±20分变化。没有可比历史则留空；部分批次报告不称为完整全市场指数，不含虚构胜率或价格预测。报告在多空排名页内展示，不恢复异动筛选、预警中心、自选组合菜单。

接口：`GET /api/live/community/sources`、`GET /api/live/community/ai`、`POST /api/live/community/probe`、`POST /api/live/community/analyze`。分类和采集控制仅对开启采集的本机服务开放。新来源板块聚合仍需独立核验的成分股映射，尚未输出板块情绪指数。
