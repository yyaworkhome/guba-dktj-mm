# 界面实现依据

最终方向：专业金融暗色工作台；Vue 3响应式界面，桌面固定侧栏，手机折叠导航。概念见 `design/concept.png`，由内置Image Gen生成，非运行时页面背景。

设计提词摘要：完整中文A股情绪应用；1536×1024；深蓝背景、青色主操作、看多珊瑚红/看空青绿；顶部数据状态、左侧功能菜单；五类分析入口、可消歧搜索、交易日周期；分数分布、趋势、词频、信号、排行；所有市场数显式标为演示；Vue原生文字与图表，不使用截图伪装控件。

## 设计系统

- 背景 `#0b111b`，面板 `#111b29`，边框 `#223044`；主色 `#34d3b4`，看多 `#f47b82`；正文 `#ecf1f8`，辅助 `#91a1b5`。
- 微软雅黑/Segoe UI/system-ui；标题29px、模块17px、正文14px、辅助10–12px。桌面左右28px、模块间16px、圆角10px。
- 导航、图标使用统一线性图标；数字等宽。输入、标签、按钮同一族；候选列表明确指数/股票类型及交易所。
- 分数/图表左右两栏；词频/信号延续同一列宽；排行使用表格；移动端单列，表格局部横滚，页面不横向溢出。
- 核心状态：载入、失败、修改条件待提交、无候选、未登录、空自选、规则未触发；不静默显示旧筛选结果。

## 相比概念的必要修正

- 删除概念误生成的重复预警/AI菜单，保留用户指定的9项导航。
- 概念示例中的“看平/看跌”修正为“看空/中性”；所有日期与数值改由API模拟快照计算，不能逐字照搬虚构图表。
- 两条曲线的量纲不同，因此明确“区间缩放价格”；提供原始模拟价格明细，避免将价格读成0–100情绪分。
- 加入覆盖率、缺失维度和周期口径；工具栏提供实际Excel导出与回测入口。
- 顶部小字说明为独立品牌排版，并非新增产品功能。复盘按钮回应用户后续要求，目前明确为规则模板。

这些修正以用户功能、统计准确性和实际交互为准。无需在运行时加载概念图。
