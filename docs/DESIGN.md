# 界面实现依据

最终方向：专业金融暗色工作台；Vue 3响应式界面，桌面固定侧栏，手机折叠导航。概念见 `design/concept.png`，由内置Image Gen生成，非运行时页面背景。

设计提词摘要：完整中文A股情绪应用；1536×1024；深蓝背景、青色主操作、看多珊瑚红/看空青绿；顶部数据状态、左侧功能菜单；五类分析入口、可消歧搜索、交易日周期；分数分布、趋势、词频、信号、排行；所有市场数显式标为演示；Vue原生文字与图表，不使用截图伪装控件。

## 设计系统

- 背景 `#0b111b`，面板 `#111b29`，边框 `#223044`；主色 `#34d3b4`，看多 `#f47b82`；正文 `#ecf1f8`，辅助 `#91a1b5`。
- 微软雅黑/Segoe UI/system-ui；标题29px、模块17px、正文14px、辅助10–12px。桌面左右28px、模块间16px、圆角10px。
- 导航、图标使用统一线性图标；数字等宽。输入、标签、按钮同一族；候选列表明确指数/股票类型及交易所。
- 分数/图表左右两栏；词频/信号延续同一列宽；排行使用表格；移动端单列，表格局部横滚，页面不横向溢出。
- 核心状态：载入、失败、修改条件待提交、无候选、未登录、空自选、规则未触发；不静默显示旧筛选结果。

## 相比概念的必要修正

- 删除概念误生成的重复预警/AI菜单，保留用户指定的9项导航。
- 概念示例中的“看平/看跌”修正为“看空/中性”；所有日期与数值改由API模拟快照计算，不能逐字照搬虚构图表。
- 两条曲线的量纲不同，因此明确“区间缩放价格”；提供原始模拟价格明细，避免将价格读成0–100情绪分。
- 加入覆盖率、缺失维度和周期口径；工具栏提供实际Excel导出与回测入口。
- 顶部小字说明为独立品牌排版，并非新增产品功能。复盘按钮回应用户后续要求，目前明确为规则模板。

这些修正以用户功能、统计准确性和实际交互为准。无需在运行时加载概念图。

## 已检查的设计对照

使用内置浏览器在概念原生1536×1024及手机390×844验证，通过 `view_image` 直接查看概念与最新桌面/手机截图。实现保留暗色方向及信息层级，不逐像素复制生成图的文字错误和静态假数据。

| 比较点 | 概念 / 实现 | 处理 |
| --- | --- | --- |
| 侧栏与入口 | 左侧导航、五类模式、首屏分析表单 | 保留；删除误生成的额外AI菜单 |
| 主体结构 | 分数左、趋势右，关键词与信号下方，排行表格 | 保留；新增覆盖率折叠区与实际导出工具栏，整页略长 |
| 色彩 | 深蓝背景、青色操作、珊瑚红看多 | 保留颜色token；使用纯色面板，不复制生成图的光晕 |
| 文字与图表 | 中文金融工具层级、大小数字及趋势 | 改为原生字体与API计算；修正中性/看空标签和价格量纲 |
| 首屏文案 | 标题、副标题、模式、开始分析、数据状态 | 按用户原文保留；增加独立品牌小字、复盘入口与口径提示 |
| 移动端 | 同一信息结构单列 | 验证菜单展开、板块跳转、结果；修复隐藏表头无障碍文本造成的页面溢出 |
| 可用性 | 真实控件而非图片 | 验证候选选择、周期提交、表格明细、下载、账号、自选与预警 |

已按上述设计依据检查实现；这些明确记录的变更用于满足用户功能和统计口径，并非宣称与生成图逐像素相同。截图为验收证据，保存在本机工作区外的可视化目录中。

## 真实采样入口增量

首页默认展示东方财富近3个自然日的真实标题采样，与“全功能演示”通过明确的来源按钮切换，现有暗色token和卡片层级沿用。支持在5只白名单股票内搜索/选择，`000001` 在真实股票目录明确指平安银行，演示统一搜索仍要求指数/股票消歧。标题/正文模式单独显示数据、状态和采集命令，切换时清除旧结果并处理请求竞态。真实入口披露采样范围、数据时间、源失败、规则分类与方向明确样本数；不沿用模拟综合分、回测或资金指标。日期分组使用自然日。

样本卡片展示纯文本摘录、规则标签、来源链接、发布时间、首次发现时间和最近观察时间；未采集时明确为空，不借用其他股票或另一模式样本。详情源失败与已保存的部分样本同时显示，避免误认为完整采集成功。

本机浏览器已验证桌面、390×844手机单列、股票搜索、银行/上海股票选择、标题与正文隔离、范围切换及样本溯源。手机控件和正文摘录无页面横向溢出，控制台错误/警告为空；恢复浏览器默认视口后保留真实首页预览。增量截图保存为可视化目录下的 `multistock-body-desktop.png`、`multistock-body-mobile.png`；`live-desktop.png`、`live-mobile.png`为此前单股阶段证据。

## 妙想入口增量

沿用已有暗色工作台，不重新设计品牌。首页来源组新增“妙想数据 · 行情与板块”，其下仍使用现有面板、模式页签、输入框、青色主操作、结果表格与历史列表。新增内容对应已授权的行情/板块查询需求，没有添加装饰徽标或虚构情绪数。

设计比较依据为本项目此前的 `multistock-body-desktop.png` 和本文件的token。最新 `miaoxiang-desktop.png`、`miaoxiang-mobile.png`已通过内置浏览器截图及本机view_image直接检查。五项对照：背景/面板/边框颜色保持；29px页面标题和17px模块标题沿用；侧栏导航与页头结构保持；新查询表单沿用页签、输入及主按钮；桌面宽表与手机单列使用表内横向滚动，整页无横向溢出。新文案为查询、数据日期、接口条件及账号历史所需，替代演示复盘按钮避免来源误导。

验证路径：真实入口→妙想入口→本机测试账号→个股查询→缓存→Excel下载→板块筛选→历史回看→上证指数查询→退出。默认桌面视口1597×876与390×844通过；页面身份、非空、无框架错误遮罩、控件响应均正常，控制台出现的一次429与并发限制一致、重试成功，无未解释错误。临时手机视口已重置。

## 真实快照与观察榜增量

首页真实入口追加两个沿用现有暗色panel与字级的模块：“采集快照趋势”和“真实样本观察榜 · 5股”。前者保留时间间隔、空值和原始窗口，可切换局部横滚明细；后者明确样本门槛、排序条件、未入榜原因与观察时间，股票按钮跳转对应分析。原“已采样日期明细”改名为“按发帖日期分组”，防止误读为实时历史信号。没有增加模拟曲线或伪造排行。

内置浏览器验证图表/表格切换、排序条件响应、银行跳转、正文/标题历史隔离与刷新。当前真实样本均未达到方向数门槛，空榜与原因显示正确。默认桌面1597×876与390×844手机布局通过，手机页面无横向溢出（正文宽375px，视口390px），明细表能独立键盘横滚；验证后的日志无新增错误或警告。首次刷新前的旧热更新状态曾有字段错误，完整重载后未复现。临时视口已重置，预览恢复真实首页。
