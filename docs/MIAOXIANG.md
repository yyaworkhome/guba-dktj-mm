# 妙想真实数据查询接入

首页选择“妙想数据 · 行情与板块”，登录本系统账号后输入问句。“行情 / 财务”使用妙想查数接口，“板块 / 条件筛选”使用妙想智能选股接口。仅按用户点击调用，没有后台轮询、定时采集、自动买卖或社区互动。

## 配置与凭据

后端从进程环境读取 `MX_APIKEY`。Windows 本机进程未继承新变量时，回退读取当前用户注册表 `HKCU/Environment` 中的同名变量。密钥只作为固定妙想HTTPS地址的 `apikey` 请求头发送，页面、历史、Excel和Git中均不保存密钥。

Linux / Docker必须在服务端设置此变量，`compose.yml`已传入；不设置则接口返回503及明确配置提示。不要使用 `VITE_` 前缀，原生包和网页只连接自己的API。注册登录沿用本系统账号，与东方财富账号登录分开。全局共享服务端妙想额度，返回权限/额度错误时需检查该密钥对应权限。

此接入根据已安装官方技能包的协议实现独立Python适配器，只依赖现有httpx，不需要部署机器安装Codex、pandas或执行技能脚本。

官方入口：[妙想Skills](https://dl.dfcfs.com/m/itc4)。固定只读地址：

- `https://mkapi2.dfcfs.com/finskillshub/api/claw/query`，请求 `toolQuery`。
- `https://mkapi2.dfcfs.com/finskillshub/api/claw/stock-screen`，请求 `keyword`。

## 行为与边界

- 问句2～160字。代码带名称/交易所，例如“上证指数000001.SH最新收盘价”，避免 `000001` 自然语言匹配歧义。页面保留接口实际识别的证券/条件，查询结果可能与用户意图存在偏差，需核对。
- 数据发生时间以表格日期为准；获取时间使用北京时间显示。自然语言“最新价”可能被接口解释为近期收盘价，不保证逐笔/盘中实时，也不将日期后缀“日”解释为星期。
- 结构化结果按原单位保留为文本，日期维度、指标名、筛选列日期和复权参数随结果保留。不会将不明单位的字符串自动转换成行情数值。
- 保留最多8张表、每表50行和24列，单元格最多1500字符；超过行列上限明确显示限量。Excel与保存/展示范围一致。零匹配结构化筛选表显示为空；缺少结构化表格、仅Markdown返回、未支持的格式会报错，不猜测解析。
- 同账号、相同类型和完全相同问句的成功记录十分钟内直接复用，保留原获取时间。缓存过期后追加记录，不更新原结果；失败也保存单独记录，绝不以旧结果冒充本次成功。
- 只返回规范化表格和来源信息，不保存完整响应或请求头。上游错误不原样返回，使用受控的权限、额度、超时、结构变化等错误说明。
- 单进程同时只允许1次上游查询，总计最多5次/分钟、30次/小时；缓存命中不占上游次数。单响应最多2MB，请求/读取超时15秒，不跟随重定向、不自动重试。多worker/多节点上线前应改为共享限流和任务锁。
- 新表 `provider_queries` 保存账号、原问句、查询类型、开始/获取时间、成功或失败及规范化结果。追加建表不修改已有表。历史只返回当前账号最近20次，按ID读取和Excel也校验账号归属。
- 与 `sentiment_snapshots`、`quote_observations`、演示行情和回测隔离。板块当前筛选不能冒充过去生效的行业成分；资金指标不能直接归因为真实主力行为。真实情绪与价格关联研究仍待持续快照、交易日历及分类模型。

## API

| 接口 | 行为 |
| --- | --- |
| `GET /api/mx/status` | 仅返回是否配置，不返回密钥 |
| `POST /api/mx/query` | Bearer登录；JSON含 `kind=data或screen`、`query` |
| `GET /api/mx/history` | 当前账号最近20次记录 |
| `GET /api/mx/history/{id}` | 当前账号已保存结果，不触发外部请求 |
| `GET /api/mx/history/{id}/export` | 当前账号结果导出；字符串强制按文字保存，防止Excel公式执行 |
