# 多空研究台界面约定

以深色金融工作台为默认主题。横向导航和表格保持研究终端的信息密度，手机端使用横向导航与单列内容；浅色主题共用功能与数据。

## 导航与首屏

总览、个股分析、智能决策、多空排名、大盘行情、板块行情、历史数据、持仓管理。

按用户最终确认，不显示异动筛选、预警中心、自选组合。持仓管理是当前证券的本地风险测算，不恢复自选组合。历史数据使用真实采集快照；真实策略回测未完成前不以模拟胜率作为入口内容。

首页由左侧股票输入、右侧每日扫描、横向结果摘要、双列多空排名和分析明细组成。输入需先选择核验证券，再开始采样。周期、采样口径、当前证券、数据时间与样本质量始终可辨认。

## 视觉体系

- 深蓝黑背景、蓝灰面板、细边框，青绿色用于选中态和主要动作。
- 看多为红色、看空为绿色，未识别为灰色；任何颜色都配有文字。
- 标题、统计数字、输入标签与说明形成明确层级，控件字体继承系统中文字体。
- 首页保留双列表格，不用装饰性卡片替代排行榜。
- 不用虚构行情、填充图表或预置收益来撑满版面；空结果说明未达标原因。
- 手机版输入、主按钮与表格按容器宽度收排，导航可横向滚动，页面本身不横向溢出。

## 相对概念稿的有意调整

新增智能决策、持仓管理是用户确认的范围。实际采样需要标题/正文口径、读取记录、任务进度和失败处理，因此首屏比视觉概念多出必要控件。批次选择和CSV使历史排名可追溯。示意排行榜换成实际任务结果，未达门槛时留空，不填入演示股票。

决策页显示缺项、覆盖权重、数据截止和条件否决原因。技术值来自保存日线；仓位与持仓在浏览器计算，资金不上传。设计应优先让用户分辨“能计算的参考值”和“尚未核验的执行条件”。

## 验收准则

在1536×1024、普通桌面和390×844验证：首页有意义内容、无框架错误、无整页溢出，输入/分析、扫描控制/CSV、风险计算、持仓数量校验及深浅主题可用。视觉对照至少核对导航文案、布局、字阶、配色、边框间距、图标与移动端折行。运行截图和临时验收记录置于仓库外，避免把机器路径与临时数据作为项目资产。
