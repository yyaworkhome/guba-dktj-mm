# 多空研究台｜产品需求与页面规范（3.0）

## 1. 产品定位
面向 A 股研究者的散户情绪量化研究平台。以东方财富股吧为首个舆情来源，后续通过数据源适配器扩展其他合规来源；将帖子级观点识别、用户去重、情绪统计、行情对照、异动发现和 AI 解释整合到统一终端。

本产品是研究与辅助决策工具，不输出确定性收益承诺，也不把情绪分数等同于买卖指令。

## 2. 已确认范围
- 市场：全部 A 股，股票池每日同步，支持暂停、续扫、失败重试。
- 首发舆情源：东方财富股吧；后续可增加经授权的财经社区、新闻及公告来源。
- 终端：响应式网页优先；后续复用同一套 Web 前端封装 Android（Capacitor）与 Windows（Tauri）。
- 视觉：参考用户提供的深色金融终端布局；暗色为默认主题，保留浅色主题。
- AI：个股自动生成情绪摘要、观点依据、主要分歧、变化解释与风险提示。
- 分析周期：今日、近 3/5/10/20 日；所有指标显示统计窗口与数据更新时间。

## 3. 信息架构
顶部主导航：
1. 总览
2. 个股分析
3. 多空排名
4. 大盘行情
5. 板块行情
6. 异动监控
7. 历史数据
8. 自选组合

### 总览页
- 顶栏：品牌、导航、主题切换、数据状态、最后更新时间。
- 股票搜索：支持代码/名称；回车搜索；显示交易所与证券简称。
- 周期切换：今日、3日、5日、10日、20日；开始分析。
- 市场概览卡：全市场情绪指数、看多占比、看空占比、有效独立用户数、帖子数、覆盖率。
- 趋势图：情绪指数与行情指数/涨跌家数对照；可切换 24 小时、3/5/10/20 日。
- 排行区：看多、看空、情绪升温、情绪降温、分歧扩大；列出股票、分数、样本数、变化幅度。
- 全市场扫描：扫描批次、进度、成功/失败/待处理、最后运行时间、开始/暂停/继续/重试。
- 异动与 AI 摘要：仅展示有足够样本且可追溯的事件。

### 个股分析页
- 股票基本信息与行情快照。
- 情绪总分（0-100）、看多/看空/中性/未识别分布、独立用户数、有效帖子数、样本质量提示。
- 情绪与价格双轴趋势图。
- 帖子时间分布、观点强度、重复内容占比、用户参与度。
- 代表性多头/空头观点（脱敏展示、原文链接、发布时间、分类置信度）。
- AI 解读：事实摘要、情绪变化、分歧点、风险因素、证据链接、模型置信度。
- 明确显示“样本不足/数据延迟/数据源不可用”，不以虚构数据填充。

### 多空排名
- 多头强度、空头强度、升温速度、降温速度、分歧程度五类榜单。
- 支持交易所、板块、样本门槛、周期筛选。
- 默认按独立用户数和有效样本质量过滤；可查看过滤原因。

### 大盘行情 / 板块行情
- 大盘：指数、涨跌家数、涨跌停家数（数据源可用时）、全市场情绪趋势。
- 板块：行业/概念情绪热度、情绪变化、代表股票、样本量。
- 不将股吧情绪误称为资金流或主力行为。

### 异动监控
- 情绪突增/突降、价格与情绪背离、讨论热度异常、分歧扩大、样本质量突变。
- 预警包含触发规则、时间窗口、样本量、对照基线、证据帖子。

### 历史数据
- 情绪与后续收益分布、分组统计、事件研究、滚动回测。
- 严格按当时可获得数据计算，防止未来数据泄漏；纳入停牌、涨跌停、交易日历、交易成本等限制。
- 报告展示样本区间、样本数量、缺失率、基准和局限性。

### 自选组合
- 自选股票批量情绪概览、变化提醒、列表导入导出。
- 用户可设置样本门槛和预警阈值。

## 4. 指标口径（首版）
- 观点类别：看多、看空、中性、无法判断。
- 帖子有效性：去广告/灌水/重复内容；保留原始记录及过滤原因。
- 用户去重：同一数据源用户在同一统计窗口内按唯一用户计数；另行展示帖子数，防止高频发帖用户放大权重。
- 情绪指数：首版使用有效观点的多空净倾向映射至 0-100；中性和未识别不计入多空分母，但必须单独展示。后续通过历史回测校准权重。
- 样本可信度：不只由帖子数决定，同时考虑独立用户数、观点可识别率、重复率、来源覆盖、时间新鲜度。
- 情绪变化：当前窗口与同长度前置窗口比较；显示绝对变化和相对变化。
- 分歧指数：看多与看空观点同时活跃的程度，不能简单用看多+看空占比代替。
- 所有分数都显示计算口径版本，避免版本变更后历史数据不可比。

## 5. 关键交互
- 搜索股票后进入个股分析；周期切换会刷新所有关联指标。
- 扫描任务支持启动、暂停、恢复、失败重试；后台异步执行，前端轮询/推送状态。
- 图表可切换指标、周期、显示/隐藏行情序列。
- 所有 AI 结论可展开查看依据与原始帖子链接。
- 空状态、加载状态、错误状态、数据延迟状态均需设计。
- 暗色/浅色主题切换，偏好持久化。

## 6. MVP 验收标准
1. 股票搜索可按代码/名称查找并展示证券信息。
2. 可查询某只股票指定窗口的帖子样本与统计。
3. 帖子分类结果包含类别、置信度、模型版本和可追溯来源。
4. 重复帖子与重复用户按规则处理，帖子数和独立用户数分开展示。
5. 全市场扫描任务有进度、成功/失败数、失败原因与重试能力。
6. 所有空数据明确标记，不显示伪造的“实时”数字。
7. AI 个股解读引用统计结果和可追溯证据，不凭空补充行情事实。
8. 所有来源接入遵守服务条款、授权、访问频率和隐私要求；不绕过登录、验证码或访问控制。
