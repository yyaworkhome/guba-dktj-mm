当前支持在线搜索并核验沪深北A股，以下5股保留为初始快捷观察样本；新增股票不再受此列表限制。标题与正文分别保存为 `eastmoney-title-v1`、`eastmoney-body-v1`，同一证券行情观察共享，帖子不跨模式混用。

| --- | --- | --- |
| `XSHE:300059` | 东方财富 | 0 |
| `XSHE:000001` | 平安银行 | 0 |
| `XSHE:300750` | 宁德时代 | 0 |
| `XSHG:600519` | 贵州茅台 | 1 |

真实采集接口拒绝裸代码 `000001` 和指数 `XSHG:000001`，不隐式替换为银行或指数。首页全A股搜索返回同代码的股票和指数候选；指数显示“请使用大盘栏目”，不能作为个股采样对象。目录校验股票类别、交易所、市场号与QuoteID，接受沪市6开头、深市00/30开头、北交所920开头的明确证券ID；前缀匹配不足以证明存在，新证券采集前必须精确核验。旧代码、退市或目录未收录对象可能无法匹配，不能承诺源站永久覆盖任何证券。

搜索使用固定公开地址 `https://searchapi.eastmoney.com/api/suggest/get`，仅传入input/type/count，不跟随重定向；最多200KB、15秒超时。按查询缓存30分钟，最多256项；每IP每分钟最多30次手动搜索。返回最多20个候选，只持久化已核验A股。远程不可用时明确提示并仅返回已保存候选，不制造代码或代用模拟数据。原有演示名称/别名保留，真实展示使用独立的 `scope.live_directory` 元数据。

## 数据来自哪里

- 股吧公开列表：`https://guba.eastmoney.com/list,{代码}.html`，如[300059股吧](https://guba.eastmoney.com/list,300059.html)。读取HTML内的 `article_list` JSON，不执行页面脚本、不登录、不携带用户凭据。
- 普通帖子详情：`https://guba.eastmoney.com/news,{代码},{数字帖子ID}.html`。读取 `post_article` JSON，校验帖子ID、股吧、作者和完整发布时间与列表一致后保存正文。HTML只提取纯文本，去除脚本/样式；不采集图片文字、附件或评论内容。
- 行情公开接口：`push2his.eastmoney.com/api/qt/stock/kline/get`。`secid={核验后的市场号}.{代码}`、日线 `klt=101`、未复权 `fqt=0`、最多30条，校验返回代码、市场、日期与价格范围。接口为网站当前可访问形式，可能发生变化，没有可用性承诺。
- 2026-11-06本机验证两者均返回200；这只证明当时可访问，不保证长期稳定。源页面与接口字段均按不可信输入处理。

采集只允许固定域名下按证券代码生成的精确列表、行情与数字帖子详情地址，不接受用户输入URL、额外查询参数或重定向。单响应最多2MB、请求超时15秒；没有自动重试、代理绕过或验证码处理。403/429、空列表、结构变化均记录为失败；正文批次遇到HTTP或身份/结构校验错误停止后续详情请求，已成功样本按部分成功保存。详情才暴露的转帖、非普通讨论、置顶或企业标记仅筛除该候选，继续下一个。

## 标题与正文样本规则

1. 只纳入原始 `stockbar_code` 与所选股票一致、普通讨论 `post_type=0`、正常状态的帖子。保守排除热门推荐、置顶条目、跨吧文章、企业标记账号及显式转帖；无法识别所有广告、营销或机器人，不将剩余账号认定为真实散户。
2. 原始发布时间使用 `post_publish_time`，完整年月日，按北京时间解释后转为UTC入库。`post_last_time` 是最后更新，不能用于发帖时间或情绪信号发生时间。
3. 标题模式只保存标题；正文模式按发布时间选择最新的1～5个候选获取详情，分类内容为标题加正文（避免相同标题前缀重复）。文本上限10000字，页面只展示短摘录。未获取评论文本、全部点赞/转发数据或完整分页。首页排序通常受最后互动时间影响，即使再按发布时间选取也只来自这一页，存在活跃讨论选择偏差；新增记录数量不能解释为全股吧新增发帖量。正文规则尚不识别跨证券引用、反讽或长文本语义主体。
4. 保存源帖子ID、作者散列、首次发现时间、每次不同标题/互动计数的修订与规则分类。已见过的同一版本不重复分类；修订和分类使用服务端真实时间，不回填为发布时间。
5. 分析先选择截止时点可见的最新修订及规则结果，再进行内容去重，每位作者每个北京时间自然日最多3条。同内容跨作者出现只计一次。标题有轻微改写的营销内容不保证去除。
6. 阅读与评论是所选模式有效样本的当前累计计数，不是期间增量；评论内容未分类；阅读量不等于独立阅读人数。互动量不为方向分类加权。

## 分数与历史

舆论分为 `100 × 看多 / (看多 + 看空)`。没有方向明确的样本时为null，页面显示“—”。中性包括未识别和多空冲突，不表示模型已确认用户中立。页面同时显示方向明确样本数，舆论分不能替代完整五维综合分。

成功获取帖子后生成一个 `data_mode=live`、`version=live-{titles或body}-run-{id}` 的采集时点快照。旧单股版本的 `live-title-run-{id}` 历史记录保留。快照可用时间是本次采集完成时间，即使帖子发表于过去，也不能假设当时系统已知道它。按自然日展示的明细只是已采集帖子的发布日期分组，不是当日曾实时可用的历史信号。

首页“采集快照趋势”单独读取最近30天内、当前截止时点已经创建且可用的真实快照，按证券/标题或正文严格隔离，不用今天的修订和分类重新计算过去。每点保留原始分数、有效样本、作者、方向数、统计窗口和可用时间；最多显示最近200点并披露总数，不平均压缩。横轴为实际采集时间，无方向样本为null、断线，不同长度或未知窗口不连线。它与上方自然日筛选独立；没有接入前的历史就显示缺失，不补造。

“真实样本观察榜”比较已运行采集的股票及初始5股，范围随采集扩展；仅搜索未采集的新股不扩充榜单。使用同一个查询截止时点、自然日窗口及内容模式。入榜需有效样本≥20、作者≥10、方向样本≥10，且最近成功或部分成功帖子观察未超过24小时；可按舆论分、看多/看空占比或有效样本量降序排列。未达标不授予名次，逐项显示原因。门槛为尚待统计校准的开发规则，不能当作可靠性或收益保证。样本量不是新增发帖速度，各股采集时间和选择偏差仍可能不同，不把该榜解释为全市场排名、热度增速或选股信号。

日线批次追加到 `quote_observations`，保存获取时间；不同批次不相互覆盖，当前交易日数据可能未收盘。未复权历史价格不宜直接用于跨除权日收益率。真实分支暂不发布背离结论、胜率或预测回测；演示回测固定读取demo-v1，不能混入真实帖子、手动工作台或本次行情。

## 运行与接口

在项目根目录运行：

```powershell
# 默认东方财富、标题模式
.venv/Scripts/python.exe -m backend.collect
# 明确股票、正文模式；limit允许1～5，默认3
.venv/Scripts/python.exe -m backend.collect --instrument XSHG:600519 --content body --limit 3
```

默认使用当前 `DATABASE_URL`，未指定则写本机SQLite。采集与服务须使用同一配置；容器部署可在app容器中运行 `python -m backend.collect`。本次没有配置系统定时任务、Codex自动化或后台轮询。

CLI会核验并创建新证券目录项，无需生成演示数据；初始5股仍可直接创建。若希望演示并存，可在API启动时设置 `SEED_DEMO=true`；真实查询始终不读取演示快照。

首页“开始真实分析”使用 `POST /api/live/analyze`，提交证券、自然日窗口和标题/正文口径。本机公开数据分析无需账号；只有显式启用后端 `ALLOW_LOCAL_COLLECTION=true`、回环客户端、本机主机名，以及存在Origin时的本机http(s)来源，才允许访问源站。标准 `scripts/dev.ps1` 仅为API子进程启用，并以 `--no-proxy-headers` 启动；不把转发头当本机身份。冷却内复用已有同口径样本；禁用或有并发任务时仅分析已保存数据并说明原因。远程/代理生产部署保持关闭，使用服务端CLI任务。原有 `POST /api/live/collection` 继续要求账号。

首页正文每批最多请求5条详情。完成后返回真实成功/部分成功/失败及源错误，不把HTTP200解释为全成功。请求超时可能仍在服务端运行，应先刷新状态，不能反复提交。结果的 `interpretation` 只描述样本：显示有效数量、作者、方向识别率和不足原因，区分空样本/未识别方向/有限方向样本/达开发门槛的观察；价格变化只比较最近两根已保存日线，不用于推断背离、收益或未来走势。直接分析与后续查询使用相同的解释函数，历史快照原值不回写。

| 入口 | 行为 |
| --- | --- |
| `GET /api/live/search?q=000001` | 远程目录核验与消歧，返回股票/指数候选；失败时仅本机已保存候选 |
| `GET /api/live/instruments?q=000001` | 初始5股与已保存核验股票，不发远程请求 |
| `GET /api/live/collection?instrument_id=XSHE:002594` | 页面采集开关、共享锁、该股最近运行和下次允许时间 |
| `POST /api/live/collection` | 需登录且本机启用；提交instrument_id、content、limit；共用锁和10分钟间隔 |
| `POST /api/live/analyze` | 提交instrument_id、content、days、limit；返回analysis和collection；符合本机开关/来源条件才采集，其余返回已有数据与原因；无需账号、不访问私有账号信息 |
| `GET /api/live/status?instrument_id=XSHE:300059&content=titles` | 该股票/内容模式的最近采集运行、每源状态、响应摘要、筛除及采样数量 |
| `GET /api/live/analysis?days=3&instrument_id=XSHE:300059&content=body` | 仅所选股票/模式的真实样本；北京时间自然日，允许1～30日；最近5条有效样本带来源和可用时间 |
| `GET /api/live/timeline?instrument_id=XSHE:300059&content=titles` | 该证券/模式最近30天保存的采集快照，最多200点，保留当时统计窗口与空值 |
| `GET /api/live/rankings?days=3&content=titles&sort=opinion_score` | 已采集股票及初始样本榜、实际覆盖数与未达标原因；sort另支持bullish_pct、bearish_pct、effective_posts |
| `GET /api/live/export?instrument_id=XSHE:002594&days=3&content=titles` | 真实XLSX：摘要、日期分组、最近5条样本、日线、最近30天最多200快照；无方向留空，源文本强制文字单元格 |
| `GET /api/live/alerts`、`POST /api/live/alerts`、`DELETE /api/live/alerts/{id}` | 需登录；真实预警独立保存，按样本门槛与24小时新鲜度判断触发 |
| `GET /api/live/watchlist?days=3&content=titles`、`PUT /api/live/watchlist` | 需登录；统一自选清单的已核验A股对比/新增，不支持对象保留且analysis=null |
| `DELETE /api/watchlist?instrument_id=...` | 需登录；真实与演示共用同一自选关系，移除只影响当前账号 |
| 首页“读取已保存结果” | 查询数据库，不请求东方财富；需更新源站样本时使用“开始真实分析” |
| `GET /api/analysis`、`GET /api/rankings`、`/api/backtest`、`/api/export`、`/api/alerts` | 隔离的演示功能；真实预警使用live接口，妙想导出使用独立mx接口 |

CLI返回码：所需源成功为0；部分失败、全部失败、限频或锁冲突为1。每源独立保存状态，失败后保留旧观察记录并显示旧数据时间，不用演示、其他股票或标题代替正文。超过24小时无成功帖子观察会标为陈旧。同版本再次获取会更新时间状态，但不会制造内容修订。`collection_runs.details._meta` 记录模式与来源；旧无元数据运行按标题解释。

## 数据库与恢复

采集使用新增的 `collection_runs`、`quote_observations`；妙想使用 `provider_queries`，真实预警另存 `live_alert_rules`。现有帖子/修订/分类/快照模型没有改列。启动API或CLI的 `create_all` 会创建缺失表。仍未建立通用生产迁移体系；升级前先备份，生产需另行验证PostgreSQL迁移与并发行为。

本机通过 `backend/data/collector.lock` 防止同时启动，且数据库检查同一股票最近运行间隔至少10分钟，标题/正文共用限频；详情请求之间至少1秒。进程异常退出可能留下锁或running记录：先检查是否仍有采集进程，确认停止后再移走锁文件重试，不能盲目删锁并发运行，不修改历史时间规避限频。多主机部署需增加数据库级锁；本版未支持多节点采集。

源响应正文与探测文件不入Git。运行表保存响应SHA256、源URL、观察时间、筛除数量；标题修订保存内容摘要和引用链接。账号、数据库、环境文件及采样内容均由gitignore排除。

## 栏目规则与账号功能

真实排行榜、方向集中度筛选和预警共用有效样本≥20、作者≥10、方向样本≥10、最近帖子观察≤24小时的门槛。规则阈值未校准。方向集中度只在看多+看空样本内判断，70/80/90可选；它不判断情绪反转、讨论增速或价格背离。

真实预警按股票、内容模式、自然日窗口、指标、阈值保存；完全相同条件重复提交返回已有规则，每账号最多50条。可选看多占比、看空占比、舆论分，比较方向为大于等于，阈值0～100。每次查询使用同一截止时点；门槛未达标时ready=false、value=null、triggered=false并返回原因，UI展示待积累/待更新，不能解读为已经验证未触发。仅站内手动查询，不运行调度、不发送通知，也不保存虚构触发事件。

自选关系由真实与演示页面共享；真实新增允许已核验A股，初始5股可在无演示目录时直接创建。清单内原有指数/板块等对象仍保留，但没有真实情绪分。演示搜索与异动只读取具有demo-v1样本的目录；共享自选返回demo_available，真实专有股票不请求不存在的模拟分析，而是显示“查看真实数据”。账号之间查询和删除均隔离。所有live账号统计只读数据库，不访问源站。真实历史回测栏目目前提供已保存快照核查，缺完整交易日历、复权价格与可用时点一致的未来成交价格，尚不返回真实收益或胜率。
