# 多空研究台

Vue 3 + TypeScript + FastAPI 的可运行研究终端。个股情绪、每日扫描、条件式决策研究和持仓风险计算共用一套界面。独立项目，非东方财富官方产品。

仓库：[yyaworkhome/guba-dktj-mm](https://github.com/yyaworkhome/guba-dktj-mm)，开发分支 `codex/v2-core`。

## 当前页面

| 入口 | 实际功能 |
| --- | --- |
| 总览 | 股票搜索、多来源AI情绪分析、样本覆盖、每日扫描与多空排名 |
| 个股分析 | 沪深北A股核验、独立真实行情趋势、多来源采集与AI/规则分类、来源、Excel导出与历史快照 |
| 智能决策 | 六维输入检查、MA/ATR/量能技术参考、条件式方案、三种走势预案、证据和方案留痕 |
| 多空排名 | 完整目录扫描队列、暂停/继续/停止/失败重试、批次排行、未入榜原因和CSV |
| 大盘行情 / 板块行情 | 妙想真实只读查询、账号历史与Excel；不冒充情绪或资金分析 |
| 历史数据 | 实际采集时点快照；不补造接入前曲线 |
| 持仓管理 | 当前股票的本地持仓盈亏、可卖数量、保本估算、止损风险与新增仓位预算 |

按用户确认移除异动筛选、预警中心、自选组合及加入自选按钮。原有数据库记录和兼容API保留。主界面不混入模拟数据。

## Windows运行

需要Node 24、Python 3.11+：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/dev.ps1
```

打开 <http://127.0.0.1:5173>，API文档 <http://127.0.0.1:8000/docs>。标准脚本为API子进程启用本机采集及扫描工作进程；退出该脚本会停止API。

分别启动时：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r backend/requirements.lock.txt
$env:ALLOW_LOCAL_COLLECTION='true'
$env:ENABLE_MARKET_SCANNER='true'
.venv/Scripts/python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --no-proxy-headers
```

另一终端：

```powershell
npm ci
npm run dev
```

默认SQLite保存在 `backend/data/sentiment.db`，不提交Git。生产可配置PostgreSQL；服务端密钥不放入Vite变量。妙想配置见 [MIAOXIANG.md](docs/MIAOXIANG.md)。

## 个股分析

搜索代码/名称 → 明确选择证券 → 开始分析。`000001`会区分平安银行和上证指数。支持已确认的沪深北A股，源站无帖子、拒绝请求或目录不收录时显示实际原因，不能保证上游对每只股票始终可用。

新增新浪股吧/淘股吧的 DeepSeek AI 分析；来源成功率、过滤依据、模型版本与观察快照分别保存。配置和统计口径见 [COMMUNITY_AI.md](docs/COMMUNITY_AI.md)。同花顺目前只核验入口，不将空静态页视作零情绪。

原东方财富标题只请求一页普通讨论；正文单次最多5条，正文失败不借用标题。不同口径分开统计；同内容去重，每作者每天最多3条。看多/看空为保守规则识别，未识别不等于真实中性。无方向分留空，不是完整五维情绪指数，也不是AI预测。

今日/3/5/10/20日为北京时间自然日。原始发现时间、修订、分类、采集与行情观察和快照保留。阅读、评论是所保存帖子的累计数。每股票共享至少10分钟采样间隔；CLI、页面与全市场任务共用采集锁。

### 股吧暂停时仍可分析行情

个股页点击“更新行情（不采集股吧）”，智能决策页点击“更新行情并生成方案”。首选腾讯财经公开未复权日线，单次最多40根；失败只尝试一次东方财富行情备用源。无需量化软件账号，不访问股吧；行情更新与帖子采样分别计时、留痕。行情不能替代散户多空观点，样本不足时仍不生成完整综合分或买卖计划。

行情展示价格趋势、MA5/MA20、ATR14、支撑压力和成交量比，并保存来源与观察时间。部分证券历史不足或缺少成交额时，保留缺项说明；未通过数据门槛不生成交易价位。公开接口没有可用性保证，不承诺实时成交报价。近期全市场任务因验证码暂停时，情绪分析按钮只读已有样本，避免反复请求受限股吧。

## 每日扫描与排名

先同步完整目录，再创建持久化全市场任务。主目录使用新浪财经A股节点，逐页与源总数核对，并再次检查最终总数；包含当前沪深北标识，目录异常时不发布部分名单。东方财富整表适配器保留用于明确的源验证，不将非普通股票混入当前目录。

新批次可选择新浪/淘股吧 + AI或明确标注的规则分类；同一批次固定来源与模型，不混排。新来源以观察快照统计，原东方财富以近3日标题统计。

每只股票采集一页，间隔至少5秒，约5500只仅间隔就需要约8小时，还需加上网络耗时。前端每5秒读取进度；源站要求身份核实/验证码或返回401/403/429时立即暂停；普通单股解析失败留痕后继续，网络连续失败或连续10只页面异常才触发另一类暂停。网络/服务端故障最多自动重试2次，间隔11、22分钟；访问拒绝不自动重试。暂停、继续、停止和失败重试可操作，已处理结果和错误保留；重启API继续未完成任务。

每日扫描开关在数据库保存，启用后北京时间16:10检查，每自然日一次；当日已手动扫描则不重复自动扫描。休市日也采样讨论，需要电脑/API持续运行。没有系统服务安装，不承诺关机后执行。

榜单按本批采样当时的统计保存，不用后来分类回算旧批次。每股至少20条有效样本、10位作者、10条方向样本，且观察新鲜，才参与排名。进行中的任务显示“部分排名”，失败和不足样本单独披露，CSV包含全部状态。阈值是待校准开发参数。

“生成本批情绪与异动报告”展示达标股票平均舆论分、覆盖和极值，只与相同来源/模型的已完成批次比较。未完整覆盖时明确标记部分报告。AI默认每日50次调用，达到上限暂停并保留进度；全市场运行需自行设置合适的调用预算。

## 智能决策与持仓

[决策引擎口径](docs/DECISION_ENGINE.md)记录公式、数据门槛、交易单位和已知缺项。价格、仓位及条件由规则计算，AI解释尚未接入。

六维权重25/15/20/15/15/10。当前资金和市场环境等输入不足时，综合分留空并显示权重覆盖率，不将可用维度重新放大成完整100分。样本、价格或交易状态未核验时不启用买入/加仓建议。真实日线充分时展示技术位；买卖参考计划还须通过样本门槛。2R/3R为风险倍数，不是价格预测。

仓位计算只在浏览器内存进行，资金与持仓不上传、也不保存到本机存储。支持现金、已有风险、账户总风险、仓位上限、费用和滑点；根据板块交易单位向下取整。持仓模式检查今天可卖数量，提示T+1锁定。止损成交、流动性和涨跌停尚不能保证。

生成的公共数据研究方案保存版本、数据截止和原帖证据。真实收益回测、自动日/周有效性复盘仍需交易日历、复权价、执行模型和成熟历史样本，当前不输出胜率。
